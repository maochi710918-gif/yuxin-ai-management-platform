# 裕信汽車零件服務部 AI 數位管理平台

企業內部網站入口管理平台，集中管理常用儀表板、管理系統與數位工具。

## 功能

- 10 個預設網站入口，完整保留網址路徑與片段
- 依分類顯示、即時搜尋、全部／收藏／最近使用檢視
- 卡片與清單檢視切換
- 新增、修改、排序、停用與刪除入口
- 新增、修改與排序分類
- 必填欄位與網址格式驗證
- 使用瀏覽器 `localStorage` 保存所有使用者設定
- 響應式介面，支援電腦、平板與手機

## 本機預覽

使用任一靜態網站伺服器開啟專案根目錄即可，例如：

```powershell
python -m http.server 4173
```

然後瀏覽 `http://localhost:4173/`。

## GitHub Pages

專案為純靜態網站，可直接使用 GitHub Pages 從預設分支根目錄發布。
